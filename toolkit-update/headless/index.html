Install an update

  1. Close any emulator using the Tool Kit.
  2. In desktop Chrome or Edge, click Check setup port. Select the Setup / Firmware COM port, then click Enter update mode and confirm.
  3. Click Install over USB, select RP2 Boot and confirm. The updater verifies the write before restarting.
  4. Click Check setup port again and confirm the new version.

For a manual update, download the screenless UF2 and copy it to RPI-RP2 in File Explorer.

First install and recovery

Hold the Pico board’s onboard BOOTSEL button while plugging in USB. When the RPI-RP2 drive appears, release the button. Use Install over USB above or copy the screenless UF2 onto the drive.

If Windows lists generic USB Serial Devices, open Device Manager → Ports (COM & LPT) → Properties → Details → Hardware IDs. The setup port includes VID_CAFE&PID_4066&MI_0A. The browser bridge includes MI_00.
