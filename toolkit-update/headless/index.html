Install an update

  1. Download the screenless UF2. Close any emulator using the Tool Kit.
  2. In desktop Chrome or Edge, click Check setup port. Select the Setup / Firmware COM port, then click Enter update mode and confirm.
  3. Copy the UF2 to the RPI-RP2 drive in File Explorer. The Tool Kit restarts after the copy.
  4. Click Check setup port again and confirm the new version.
First install and recovery

Hold the Pico board’s onboard BOOTSEL button while plugging in USB. When the RPI-RP2 drive appears, release the button and copy the screenless UF2 onto the drive.

If Windows lists generic USB Serial Devices, open Device Manager → Ports (COM & LPT) → Properties → Details → Hardware IDs. The setup port includes VID_CAFE&PID_4066&MI_0A. The browser bridge includes MI_00.
