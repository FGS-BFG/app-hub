Install the update

  1. On the Tool Kit, open Firmware Update. Press Next until you see Install Update, then press Select twice to confirm.
  2. Click Install over USB, select RP2 Boot and confirm. The updater verifies the write before restarting.
  3. Click Check connected Tool Kit again and confirm the installed version.

For a manual update, download the UF2 and copy it to RPI-RP2 in File Explorer.

If the version check fails or the update drive is missing

Use desktop Chrome or Edge and a USB data cable. If the OLED shows COM PORTS CLOSED, press Select to reopen them. If Windows gives the ports similar names, try the Tool Kit’s COM entries until the page identifies the browser bridge.

If the update drive is missing, reconnect the Tool Kit and retry. If the firmware cannot start, hold the Pico board’s physical BOOTSEL button while plugging in USB. Release it when RPI-RP2 appears.
